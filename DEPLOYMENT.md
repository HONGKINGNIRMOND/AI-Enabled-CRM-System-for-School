## Prerequisites <a name="prerequisites"></a>

Before deploying, ensure you have:
- A production database (PostgreSQL 14+).
- Secure values for `JWT_SECRET` and `JWT_REFRESH_SECRET`.
- SMTP details for Email notifications (Optional).
- Your frontend domain and backend domain.

## Railway Deployment <a name="railway-deployment"></a>

Railway is the easiest platform for this monorepo.

### 1. Database Setup
1. Create a "New Project" in Railway.
2. Add "PostgreSQL" as a service.

### 2. Backend Service
1. Add a service from your GitHub repo.
2. Settings:
    - **Service Name**: `backend`
    - **Root Directory**: `backend`
3. Environment Variables:
    - `PORT`: `3001`
    - `NODE_ENV`: `production`
    - `DATABASE_URL`: `${{Postgres.DATABASE_URL}}`
    - `JWT_SECRET`: Generate a 64+ char random string.
    - `FRONTEND_URL`: The domain generated by the frontend service (see below).

### 3. Frontend Service
1. Add another service from the same repo.
2. Settings:
    - **Service Name**: `frontend`
    - **Root Directory**: `frontend`
3. Environment Variables:
    - `VITE_API_URL`: The domain of your backend service + `/api`.

## VPS Deployment (Ubuntu + Nginx + PM2) <a name="vps-deployment"></a>

### 1. Server Preparation
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y nodejs npm postgresql postgresql-contrib nginx
```

### 2. Database Configuration
```bash
sudo -u postgres psql
CREATE DATABASE school_crm;
CREATE USER crm_user WITH PASSWORD 'your_secure_password';
GRANT ALL PRIVILEGES ON DATABASE school_crm TO crm_user;
\q
```

### 3. Application Deployment
1. Clone the repo: `git clone <your-repo-url> /var/www/school-crm`
2. Install dependencies:
   ```bash
   cd /var/www/school-crm/backend && npm install --production
   cd /var/www/school-crm/frontend && npm install && npm run build
   ```
3. Setup Backend Environment:
   Create `/var/www/school-crm/backend/.env` with your production secrets.

### 4. Process Management (PM2)
```bash
sudo npm install -g pm2
cd /var/www/school-crm/backend
pm2 start ecosystem.config.js --env production
pm2 save
pm2 startup
```

### 5. Nginx Configuration
Create `/etc/nginx/sites-available/school-crm`:
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # Frontend (Built Files)
    location / {
        root /var/www/school-crm/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # Backend API
    location /api {
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```
Enable the site:
```bash
sudo ln -s /etc/nginx/sites-available/school-crm /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

## Post-Deployment Tasks <a name="post-deployment"></a>

### Initializing the Database
You must run the setup script the first time to create tables and the admin user:
```bash
cd backend
npm run setup
```

### Monitoring
Logs are available in `backend/logs/` or via PM2:
```bash
pm2 logs school-crm-api
```

### Security (SSL)
Highly recommended using Certbot:
```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```
